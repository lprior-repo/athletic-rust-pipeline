Introducing MeetPro Server

 

MeetPro Server provides database access to multiple MeetPro users at the same time, for a true multi-user experience.

  • Serve multiple databases from the same computer
  • Multiple users can access the same MeetPro database at the same.
  • Each MeetPro is synchronized with other users on the same database
  • Reports Only mode allows access to reports and web publishing only.


MeetPro Server requires a MeetPro license with the Server option:

Mac Installer  Windows Installer

Users Setup

Configure the passwords and permissions of your database users. A user marked "Reports Only" will be able to run reports, publish to scoreboards and publish to the web (FTP, S3, Upload to Web, Score) but not affect the database.

Connect From MeetPro

MeetPro connects to MeetPro Server from the Multi-User menu. Enter the IP address or hostname, select a user and enter a password. After login, select an available database.
