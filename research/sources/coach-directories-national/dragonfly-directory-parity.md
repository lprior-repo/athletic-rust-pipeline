bodies. The reference is `census-prototype/parsers/dragonfly_directory.py` run over
`crates/census-crawl/tests/fixtures/coach_directories`, and the Rust side is
`coach_directories::parse_directory` plus the `directory_school` mapping. Both were executed; the
numbers below are measured, not derived from the code.

## Divergences recorded

1. **Rows without `shortCode`.** The prototype appends the school row without a `detail_url`; the
   Rust lane answers `DirectoryAdmission::MissingShortCode` and mints nothing. All 3,693 captured
   rows carry a short code, so the captures do not instantiate the difference. The Rust behaviour
   is deliberate: a row with no short code has no summary to fetch and no association identity to
   store, and the survey skips it for the same reason.
2. **Raw `dragonfly_levels` is not persisted.** The prototype's `schools.jsonl` row carries the
   whole free-key map; Rust projects one flat `CanonicalSchool::classification` and drops the rest.
   [ADR-016](../../../docs/adr/ADR-016-merge-and-identity-semantics.md) decision 4 forbids adding store
   fields to chase the old JSON, so the remaining keys (region, conference, district, alignment)
   are not recoverable from the store. Recorded, not deferred silently.
3. **Classification key rule.** The first Rust rule accepted keys ending `classification(s)` only.
   Live AHSAA pages name the class `ahsaaClass`, which that rule misses: Alabama contributed 0 of
   its 793 rows. The rule now also accepts a key ending `class`, still first-non-empty-string in
   sorted key order. Measured coverage after the change: 1,336 of 3,693 rows carry a class
   (AL 485/787 admitted, GA 157/997, WY 73/91, NC 450/451, GHSA p2 171/1000, AK 0/355). The 4-row
   gap against an independent count (1,340) is exactly the classified subset of the 12 rows
   dropped as vendor fixtures (NC 1, AL 6, GA 3, WY 2).

## What is not established

The comparison covers parsing and row mapping, not fetching, caching, pacing or the store write.
No prototype `out/` artifact was reproduced for these pages, and the golden covers three of the
six compared pages.
