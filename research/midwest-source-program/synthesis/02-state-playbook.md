## Reading the table

- **AN-seed quality tiers.** Tier A (association publishes real AN ids/URLs): OH, IL, MI, SD, NE(meets), ND(meets via AthleticLIVE), MN(state meet). Tier B (timer/white-label publishes AN ids): IA, MN, WI (partial), ND full athlete ids. Tier C (names only, seed by tuple): MO, KS, IN, and most regular-season meets everywhere.
- **Independent Co2027 evidence without AN.** Best: OH (state PDFs + myOHSAA), IL (qualifier lists), WI (tournament PDFs + MileSplit rosters), MI (finals PDFs + rosters), IN (TFRRS year), ND (Firebase `y`). Weakest: MO/KS/SD (state finalists only).
- **Coach coverage reality.** Emails: WI, IL, OH (+ opt-in IA/SD via Bound). Names only: MN(AD email too), MI(AD), NE, ND, KS(AD email). None: MO, IN.
- **AthleticLIVE is not independent of Athletic.net.** It is AN's white-label; using it avoids the Cloudflare block and usually hands over AN athlete/meet ids — a compliant, faster *read path to the same ecosystem*, not corroboration. Where the PrimeTime/Karmarush ToU applies (WI live, Franklin Firebase), it is off-limits without a license [22].
